// 트러블 슈팅

아무래도 혼자해야하고 미숙하다보니 ai를 끼고했는데 얘네가 제가 쓴 코드를 다 알고있는것도 아니라서 하나를 건들면 하나가 터지고 이런 느낌이 반복 됐습니다.
그래서 점점 코드를 읽어서 이건 이게 아니지 않냐는 식의 질문으로 바뀌어서 진행했더니 해결을 빠르게 할 수 있었습니다.
코드를 직접 치라고하면 잘 못하지만 이제 무슨 코드고 왜 썼는지는 대충 알 수 있을 것 같습니다.
모를 때마다 이거 왜그러는지 이해시키라고 해서 이해하고 넘어가는 방향으로 공부했습니다.
아무래도 유니티 자체에는 익숙한 편이라 코드는 어렵지만 유니티 설정할때는 좀 빠르게 진행할 수 있어 시간내에 얼추 마무리 한 것 같습니다.

이게 점점 얽히는게 많다보니 한군데에서 고쳐도 다른곳에서도 고쳐야하는 경우가 많았는데
예를 들어 수분시스템을 넣을때 ui에도 반영을 해주어야해서 플레이어와  ui모두 고쳐야한다거나,
건설시 마우스커서보이고 꺼지는 것.
esc 키가 있으면 편할 것 같아서 추가하는 것 등의 간단한 것들은 당연히 있어야한다고 생각해서 구현했는데
역시 기능 하나를 추가할때 연계된 것도 많고 신경써야할 것들이 많다는 것을 다시한번 알게 되었습니다.

회사에 지쳐서 퇴사하고 1인 개발을 위해 나온거였는데 이렇게 꽤 오랜시간 진득하게 전반적으로 경험해보니 더욱 좋았습니다.
코드를 조금 더 잘 하게 되어서 아트와 플밍을 접목시켰을때 일을 조금 더 효율적으로 코스트가 적게드는 방향으로 진행할 수 있는 사람이 되고싶습니다.
